# 📅 Important Dates — Счётчик важных дат

Веб-приложение для отслеживания важных дат и праздников. Показывает текущее время, ближайший праздник, прогресс до него, список российских праздников и позволяет посчитать разницу между двумя датами.

Живая демонстрация

[Открыть сайт](https://magglik.github.io/important-dates/)

Возможности

- Живые часы — текущее время обновляется каждую секунду
- Сегодняшняя дата — всегда под рукой
- Ближайший праздник — автоматически определяется и показывается крупно
- Прогресс-бар — визуально показывает, сколько времени прошло до праздника
- Список российских праздников — Новый год, Рождество, 23 Февраля, 8 Марта, 1 Мая, 9 Мая, День России, День народного единства
- Разница между датами — вводишь две даты, получаешь разницу в днях, годах, месяцах
- Своя дата — узнать, сколько дней осталось до любого события

## 🛠️ Технологии

- HTML5 — структура страницы
- CSS3 — оформление, градиенты, адаптивность
- JavaScript — вся логика: работа с датами, массивами, DOM, setInterval
